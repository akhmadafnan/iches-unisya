**Status:** Academic Editorial visual direction selected; exact components, layout, hero, photos, interaction patterns **NOT LOCKED**. User wants AI to propose coherent complete designs, then revise, **not require individual approval of every component**.

## Originality and sources

- AICIS: https://aicis.uinssc.ac.id/ — conference data depth and features; homepage has theme/date, live countdown, conference navigation, submission timeline, tracks, FAQ, downloads and participant facts. **It also has Administrative Check in its own process; ICHES MUST NOT clone that workflow.**

## Identity

- ICHES: The 6th International Conference on Humanity, Education, and Society, 2027; identity includes stylized orange→gold “H” element.
- Theme: “ISLAMIC VALUES IN A CHANGING WORLD: EDUCATION, ACCOUNTABILITY, AND SOCIAL RESILIENCE FOR INCLUSIVE DEVELOPMENT.”
- Brand palette: forest #164734; ivory #F7F6F1; near-black #17211C; gold #B79A5B. Gold is accent, not every border.
- Typography: Inter paragraphs/controls, Sora for selective heading; Arabic fallback supports proper shaping. Use fluid type scales, readable line lengths, editorial rhythm.
- No carousel. Prefer static photographs and content-driven sections to decorative patterns.
- Design desktop and mobile in tandem, and check AR RTL separately.

## Content hierarchy candidates — all revisable

Header: brand, clean nav, EN/ID/AR, Login/Dashboard, optional secondary CTA.
Hero: editorial statement/theme, real event essentials, CTA and authentic image only when useful.
Countdown: **mandatory functional public feature**, four values (days, hours, minutes, seconds), positioned as an editorial event-essential element. Display variant (inline/horizontal/compact) editable from CMS; do not force it into Hero if another section works better.
Then About, CFP/Submission Journey, Event Timeline, Tracks, Programs, Speakers, Publication/Proceedings, Partners, Downloads, FAQ/Contact. Some may live on inner pages; sections can be hidden/reordered.
Use authoritative source states for CFP CTA; before submission open, do NOT show enabled Submit or Pay first.
No fabricated “speakers coming from 28 countries” statistics. If real numbers exist, show source and updated time.
Avoid heavy “Card City”: vary narrative prose, numbered stages, photography, timelines and typographic lists.

## Design-level quality review

- At first glance: ICHES name, theme, main CTA, official event date distinguishable in seconds.
- Hero feels authored by a designer, not a default Tailwind/AI gradient template.
- Countdown integrated into hierarchy, no double counting with unrelated programs. **Main conference starts Jan 5 2027; precise start time must come from Admin**.
- Desktop/mobile crop and visual order remain intentional; hero never forces tiny text under huge photography.
- Sections have meaningful differences in composition; no repeated four identical cards for every topic.
- Content hierarchy EN, ID, AR faithful to real source text; never machine-invent institutional titles.
- Footer and inner pages consistent with homepage, without every page repeating one giant hero.
- Unconfirmed speaker, journal, partners = omitted or truthful placeholder, never invented.

## Examples of revisable variants
